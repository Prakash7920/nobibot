Auto trading · local paper

Automatically opens paper orders on replay signals. Broker demo and real-money order execution are not enabled in this version.

One open trade maximum · No Martingale · Limits apply per replay run and UTC replay day. Pause preserves open positions; use Next candle to settle them.

Connection & version

NOBI TRADE v0.1 — working research build

  1. Run START_NOBI.bat for offline replay and CSV backtesting.
  2. For the experimental broker feed, install Python 3.12+ and run INSTALL_CONNECTOR.bat.
  3. Close the existing app, then run CONNECT_QUOTEX.bat. Enter credentials in the local terminal.
  4. Compare exact symbol, price, timeframe and UTC time with the broker before evaluating signals.

Connector: unofficial PyQuotex, pinned revision a50a030b. Broker access is unverified on your account. No CAPTCHA bypass or automatic fallback source.

This build has no broker buy/sell implementation. Real account switching, broker demo orders, external AI models, chart alerts, cross-market scanning, and automatic withdrawals remain future work.
